# Strum

Strum is a small menu bar app that adds gestures to your Mac's trackpad. It's in beta.

**[Download the beta](https://github.com/Jasshl/strum/releases/latest/download/Strum.dmg)** · [Website](https://jasshl.github.io/strum/) · [Help](https://jasshl.github.io/strum/help.html) · [Privacy](https://jasshl.github.io/strum/privacy.html)

Needs macOS 27 and a Mac with Apple silicon.

## Installing

The beta isn't notarized yet. Drag Strum to Applications and open it, then go to System Settings › Privacy & Security and click Open Anyway. The [website](https://jasshl.github.io/strum/#install) has the full steps.

## Reporting a problem

Choose Copy diagnostics in Strum's menu, then [open a report](https://github.com/Jasshl/strum/issues/new/choose) and paste it in.

If the pointer or keyboard gets stuck, press Control-Option-Command-Escape.
